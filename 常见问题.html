📋 常见问题 FAQ

双击一键启动.bat 后窗口一闪而过？

说明 Python 没有正确安装或未添加到 PATH。请重新安装 Python，务必勾选 "Add Python to PATH"（安装界面的底部复选框）。安装完成后重启电脑再试。

启动后浏览器没有自动打开？

手动在浏览器地址栏输入 http://localhost:5000 即可访问仪表盘。如果也打不开，检查命令行窗口是否报错。

AI 评估全部失败 / 返回 0 分？

检查以下几点：① API Key 是否正确粘贴（在仪表盘「系统设置」中查看）；② API Key 是否已激活（去阿里云百炼控制台确认）；③ 账号是否有余额/免费额度；④ 模型名称是否正确。建议先用 qwen-plus 测试，这个模型响应最快。

脚本启动后一直显示"扫描中"但不发送？

可能原因：① 匹配度低于阈值（默认70分），岗位全部被过滤——检查你的候选人档案是否填写完整；② BOSS直聘页面结构更新导致脚本无法识别按钮——检查是否有更新版本；③ 确认你是在 BOSS直聘的搜索结果页（URL 包含 /web/geek/），不是在详情页。

发送的是系统默认招呼语而不是 AI 生成的？

这是常见问题。BOSS直聘的输入框是特殊组件，脚本已做了多策略注入。如果仍然失败：① 检查控制面板的日志，看招呼语是否已生成；② 尝试先手动在聊天框随便发一条测试消息，确认输入框可用；③ 刷新 BOSS直聘页面后重试。

会不会被 BOSS直聘封号？

本工具严格模拟真人操作节奏（间隔随机 20-60 秒、每 10 个长停顿 3-5 分钟），每日上限 150 次在平台允许范围内，且仅发送个性化招呼语而非重复模板。已有大量用户正常使用，无封号报告。但任何自动化工具都存在理论风险，请在了解风险的前提下使用。

Mac 系统能用吗？

后端 Python 部分完全兼容 Mac/Linux，但 一键启动.bat 是 Windows 批处理脚本。Mac 用户需要手动在终端执行：pip install -r requirements.txt 然后 python app.py。Tampermonkey 浏览器脚本跨平台兼容。

数据存储在哪里？安全吗？

所有数据（API Key、简历、发送记录、设置）都存储在 你自己的电脑 上（C:\Users\你的用户名\JobReports\），不会上传到任何服务器。AI 评估请求仅发送岗位 JD 文本到阿里云百炼 API，不包含你的个人身份信息。

可以同时在多台电脑上用吗？

可以。将解压后的文件夹复制到另一台电脑，重新配置即可。注意：两台电脑的发送记录不互通，配额是各自独立的。

如何获取更新？

关注发布渠道获取最新版本。更新时只需替换 app.py、config.py 和 tampermonkey/boss-automation.user.js 三个文件，不会覆盖你的个人数据。

AI 模型选择哪个好？

qwen-plus 速度快、成本低，日常使用首选；qwen3.7-max 评估最准确但较慢（约 25 秒/次）；kimi-k2.7 综合均衡；deepseek-v3 逻辑严谨。建议先用 qwen-plus 跑通流程，再根据需要切换。

匹配度阈值设多少合适？

70 是平衡点——既能过滤明显不匹配的岗位，又不会漏掉太多。如果你想更激进（投更多），降到 60；想更精准（只投高度匹配），提到 80。

弹窗提醒"切换到消息页采集状态"是什么意思？

这是每日定时功能（默认 19:50），提醒你打开 BOSS直聘的消息页，脚本会自动读取每条对话的状态（已读/未读/已回复），更新到仪表盘中，这样你就能知道哪些岗位回复了你。

买错了 / 不会用能退款吗？

虚拟商品一经发货不支持退货。但如果在安装过程中遇到任何问题，提供免费的远程协助服务，直到你能正常使用为止。购买前请确认自己的电脑满足使用条件（Windows 10+ / Python 3.10+ / Chrome 或 Edge 浏览器）。
