🤖 求职自动化系统

BOSS直聘自动打招呼 + AI 智能匹配 · 安装指南

预计安装时间：10 分钟

1安装 Python 环境

本系统需要 Python 3.10 或更新版本。

  1. 打开 Python 官网下载页
  2. 点击黄色按钮 "Download Python 3.x.x" 下载安装程序
  3. 运行安装程序
安装时务必勾选底部的 "Add Python to PATH"（添加到环境变量），否则后续步骤会报错！

安装完成后，可以按 Win + R，输入 cmd，然后输入 python --version 验证。

2注册阿里云百炼 API Key

AI 智能匹配功能需要调用大模型，使用阿里云百炼平台（新用户有免费额度）。

  1. 打开 阿里云百炼 API Key 页面
  2. 登录阿里云账号（没有就先注册，支持支付宝/淘宝登录）
  3. 点击 "创建 API Key"
  4. 复制生成的 Key（格式：sk-xxxxxxxxxxxxxxxx）
  5. 妥善保存，后续步骤需要使用
免费额度约 100 万 Token/月，足够日常使用。如果用完了再按量付费，价格很低。

3安装浏览器扩展

本工具通过 Tampermonkey（油猴）脚本来操作 BOSS直聘页面。

  1. 用 Chrome 或 Edge 浏览器打开 Tampermonkey 官网
  2. 点击下载对应版本并安装扩展
  3. 安装完成后，浏览器右上角会出现 🐵 图标

4启动后端服务

双击解压文件夹中的 一键启动.bat 文件。

系统会自动：

  • ✅ 检查 Python 环境
  • ✅ 安装所需依赖库
  • ✅ 启动 Flask 后端服务
  • ✅ 自动打开浏览器到仪表盘页面
启动后不要关闭命令行窗口（黑色窗口），保持它在后台运行即可。

如果浏览器没有自动打开，手动访问：http://localhost:5000

5配置系统参数

打开仪表盘后，点击左侧 「系统设置」，填写以下信息：

配置项说明重要度
API Key粘贴第 2 步获取的 sk-xxx⭐⭐⭐ 必填
姓名 / 学历你的基本信息，AI 匹配时会引用⭐⭐⭐ 必填
量化亮点你的项目经验、技能（每行一条）⭐⭐⭐ 必填
招呼语模板 A/B/C3 个版本的个性化招呼语⭐⭐⭐ 必填
核心技能技术栈关键词，用逗号分隔⭐⭐ 推荐
期望岗位目标方向描述，如"Java后端，微服务方向"⭐⭐ 推荐
简历 PDF上传简历自动解析（最多 3 份）⭐ 推荐
匹配度阈值低于此分数不打招呼（默认 70）⭐ 建议不改
每日上限每天最多发送数（默认 150）⭐ 建议不改
候选人档案和招呼语模板是 AI 匹配的核心！不填的话 AI 无法生成有效的招呼语。

6安装浏览器脚本

  1. 点击浏览器右上角的 Tampermonkey 🐵 图标 → "管理面板"
  2. 点击 "+"（新建脚本）
  3. 用记事本打开解压文件夹中的 tampermonkey/boss-automation.user.js
  4. 全选（Ctrl+A）→ 复制（Ctrl+C）→ 粘贴到 Tampermonkey 编辑器中
  5. 检查第 51 行，确认 API_BASE 地址正确（本机运行不用改）
  6. 按 Ctrl+S 保存

7开始使用！

  1. 打开 BOSS直聘搜索页面
  2. 搜索你想找的岗位方向
  3. 页面右下角会出现 「JobBot 控制面板」
  4. 点击 「▶ 启动」按钮
  5. 脚本自动开始扫描岗位 → AI 评估 → 发送个性化招呼
保持浏览器标签页打开（可以最小化，不要关闭），脚本会在后台自动工作。建议上班前启动，下班前回来查看数据报告。

如有问题，请先查阅《常见问题.html》，或联系客服获取帮助。
